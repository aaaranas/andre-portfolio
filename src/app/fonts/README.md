# Fonts

Variable woff2 files, latin subset, self-hosted through `next/font/local` in
`src/app/layout.tsx`. One file per family covers every weight the site uses.

| File | Family | Licence |
|---|---|---|
| `space-grotesk-latin-wght-normal.woff2` | Space Grotesk | SIL OFL 1.1 |
| `jetbrains-mono-latin-wght-normal.woff2` | JetBrains Mono | SIL OFL 1.1 |
| `instrument-sans-latin-wght-normal.woff2` | Instrument Sans | SIL OFL 1.1 |

Sourced from the `@fontsource-variable/*` packages on npm.
